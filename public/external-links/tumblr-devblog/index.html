TripSit factsheets now use PsychonautWiki’s subjective effect index to describe the experiences of specific compound. Their server automatically pulls effect data from our articles and links back to their subjective effect breakdowns.

This is exciting because it’s one step closer towards creating the first universal terminology which psychonauts can finally use to describe and discuss their experiences in a formal manner.

 An example of a factsheet which uses our effect index can be found here:

  • http://drugs.tripsit.me/1p-lsd
